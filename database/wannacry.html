WannaCry

Type: Ransomware Worm

Overview

WannaCry, also known as WannaCrypt, is a ransomware worm that caused a major worldwide outbreak beginning on May 12, 2017. It encrypted files on infected Windows systems and demanded ransom payments in Bitcoin. Unlike traditional ransomware, WannaCry could also spread automatically across networks by exploiting vulnerable Windows SMB services.

Technical Details

WannaCry used the EternalBlue exploit to target vulnerabilities in Microsoft's Server Message Block version 1 (SMBv1) protocol. These vulnerabilities were addressed in Microsoft's MS17-010 security update, released on March 14, 2017. The exploit allowed attackers to execute code remotely on vulnerable systems without requiring user interaction.

Its observed capabilities included:

  • Scanning for vulnerable Windows systems
  • Exploiting SMBv1 vulnerabilities
  • Propagating automatically across networks
  • Encrypting files using cryptographic algorithms
  • Creating ransom notes
  • Using a kill-switch domain in its original variant

Kill-Switch Mechanism

The original WannaCry variant attempted to connect to a hard-coded domain before continuing its malicious activity. If the connection succeeded, the malware stopped its execution routine. A security researcher registered the domain, helping slow the initial outbreak. This mechanism was specific to certain variants and did not remove the underlying SMB vulnerability or protect against other malware using EternalBlue.

Historical Timeline

  • March 14, 2017: Microsoft releases the MS17-010 security update.
  • April 2017: The EternalBlue exploit becomes publicly available.
  • May 12, 2017: The worldwide WannaCry outbreak begins.
  • May 2017: Researchers register the original kill-switch domain, helping slow the initial outbreak.

Impact

The WannaCry outbreak affected organizations in more than 150 countries, including hospitals, businesses and public services. Estimates reported more than 200,000 affected computers during the outbreak. The incident demonstrated how an unpatched vulnerability could be used to spread ransomware rapidly across interconnected networks. It also highlighted the importance of security updates, network segmentation and reliable backups.

Research Notes

From a malware analysis perspective, WannaCry is an important example of ransomware combined with worm-like propagation. Analysts studying a WannaCry sample can examine its PE metadata, imported functions, embedded strings, file encryption behavior and network indicators. Particular attention should be paid to SMB-related activity, TCP port 445, the kill-switch domain and the creation of the mssecsvc2.0 service. Malware samples should only be handled in an isolated analysis environment.
